# Asistente de recetas

Trabajo final — MBA UCEMA

## Idea

Un agente que te dice qué cocinar con lo que tenés en la heladera. La idea surgió porque en casa
siempre terminamos tirando comida y no sabemos qué hacer con lo que sobra.

## Cómo funciona

Le paso una lista de ingredientes y me devuelve tres recetas posibles ordenadas por lo fácil que
son de hacer. Usa el prompt que está en la carpeta prompts.

Probé el agente varias veces y anda bastante bien. En general las recetas tienen sentido y usan
los ingredientes que le paso.

## Herramientas

Por ahora no usa ninguna API externa, trabaja con el conocimiento del modelo sobre recetas, que
es bastante amplio. Se podría conectar a una API de recetas más adelante para tener más variedad.

## Riesgos

Como todo sistema de IA, puede alucinar y dar información incorrecta. También hay que tener
cuidado con las alergias alimentarias. Es importante que el usuario revise las recetas antes de
cocinarlas.

## Costos

El costo es muy bajo, prácticamente despreciable para un uso doméstico.
