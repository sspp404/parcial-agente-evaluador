# Decisiones

El proyecto arrancó como una idea para no desperdiciar comida en casa.

Primero pensé en hacer algo más grande, con una app y una base de datos de recetas, pero me
pareció demasiado para el tiempo que tenía, así que lo simplifiqué a un agente que responde con
recetas directamente.

Fui probando el prompt varias veces hasta que las respuestas me gustaron. Al principio las
recetas eran muy complicadas, así que le pedí que fueran más fáciles y quedó mejor. También le
agregué que las ordene por dificultad porque me parecía más útil.

El resultado final funciona bien y cumple con el objetivo de darme ideas rápidas para cocinar
con lo que tengo.
